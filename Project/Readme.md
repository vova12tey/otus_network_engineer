## 1. Цели и задачи проекта

**Цель:** Спроектировать и настроить работоспособную сетевую инфраструктуру небольшой компании с головным офисом в Москве и филиалами в Санкт-Петербурге и Новосибирске.

**Задачи:**
- Создать схему сети и распределить адресное пространство (VLSM).
- Внедрить протоколы второго уровня (VLAN, Trunk, STP).
- Реализовать динамическую маршрутизацию (OSPF).
- Обеспечить резервирование шлюза (HSRP).
- Настроить инфраструктурные сервисы (DHCP, NAT, DNS, Web).
- Обеспечить безопасность (ACL, DMZ, ASA, SSH).
- Задокументировать проделанную работу.

## 2. Топология сети

Сеть построена по принципу "Звезда" с ядром в Москве:
- **Граница сети:** Провайдер (R_ISP) -> ASA 5505 -> R1-Main.
- **Москва (Головной офис):**
  - R1-Main и R1-Backup (резервирование через HSRP).
  - S1-Core (коммутатор ядра, собирает все магистральные линки).
  - S1-User (коммутатор доступа для ПК), S1-Server (для серверов).
- **СПб (Филиал):** R2, S2.
- **Новосибирск (Филиал):** R3, S3.

*Схема находится в папке `diagrams/topology.png`.*

## 3. Исправления и проблемы, возникшие в ходе работы

1. **Конфликт Native VLAN:** Изначально native VLAN на транках отличался (1 и 99). Это вызвало блокировку STP для VLAN 10 и 99.  
   *Решение:* Единый Native VLAN 1000 на всех транках (S1-Core, S1-User, S1-Server).

2. **Дублирование HSRP на R1-Backup:** Группа 99 была прописана дважды, из-за чего она конфликтовала с R1-Main и показывала неверное состояние `Active`.  
   *Решение:* Очистка лишних команд `standby` и настройка резервирования только на одном интерфейсе (G0/0/0.99).

3. **Отказ от GRE-туннелей (VPN):** Планировалось использовать GRE для связи филиалов, но в симуляторе Packet Tracer они работают некорректно с подинтерфейсами.  
   *Решение:* Связь филиалов реализована через **OSPF**.

4. **NAT на R1 вместо ASA:** Классические команды `global/nat` не поддерживаются в текущей версии PT для ASA.  
   *Решение:* NAT (PAT) настроен на граничном маршрутизаторе **R1-Main**.

## 4. Результаты верификации

| Что проверялось | Команда | Результат |
| :--- | :--- | :--- |
| Состояние интерфейсов | `show ip interface brief` | Все порты up/up |
| OSPF-соседство | `show ip ospf neighbor` | Все соседи FULL |
| Маршрутизация | `show ip route` | Маршруты до филиалов присутствуют |
| Резервирование шлюза | `show standby brief` | R1-Main Active, R1-Backup Standby |
| DHCP | `ipconfig /renew` | ПК получают адреса из правильных пулов |
| Выход в интернет | `ping 8.8.8.8` | Успешный ответ |
| Доступ к DMZ | `ping 10.0.99.10` | Успешный ответ |
| ACL (блокировка Бухгалтерии от ИТ) | `ping 10.0.10.2` (с PC-B) | Destination host unreachable |
| ACL (блокировка Гостей) | `ping 10.0.10.34` (с PC-Guest) | Destination host unreachable |
